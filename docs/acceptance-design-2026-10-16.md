# 全页设计更新验收记录（2026-10-16）

范围为首页及其余八个页面。设计基准见 [统一设计规范](design-system-2026-10-16.md)。

## 环境与边界

使用微信开发者工具 2.02.2608080 的原生自动化能力，操作实际 WXML / WXSS / 编译后的 JS。写入使用一次性本机 PostgreSQL、项目真实 Fastify API 和两种测试身份，不使用线上家庭作为测试数据。界面截图中的家庭名及内容都是演示数据。

微信平台外部能力单独区分：本次检查分享的活动目标、审批规则和卡片入口，通知授权分支使用本机测试配置。真实微信群发送、其他微信用户打开、订阅消息实际送达，仍需真机平台验收。

## 原生流程

| 区域 | 实际检查 |
| --- | --- |
| 页面与导航 | 九个页面打开、当前家庭名称、空家庭状态、主内容优先、按需展开编辑器 |
| 家庭创建 | 填写名称、隐私同意、创建后回到新家庭首页 |
| 成员资料 | 普通成员权限、本人资料保存、1965 年出生日期、清除生日、关闭编辑 |
| 邀请与加入 | 生成邀请、手填校验、待审批状态、管理员同意、刷新后进入正确家庭、无效卡片可换码 |
| 家庭管理 | 设置展开、最后管理员退出保护、归档后不再访问、普通成员正常退出、撤销邀请 |
| 活动 | 新建必填项、补充地点和准备事项、独立详情、回应状态、完成分工、添加分工、修改安排、完成确认 |
| 活动与记忆 | 完成活动转存；返回已经打开的家庭记录页可看到新记忆 |
| 活动分享 | 每个活动的分享目标正确，群邀请需审批，分享说明可关闭 |
| 提醒 | 日期/时间选择、新增、修改计划、停止计划确认、完成/订阅入口及状态展示 |
| 账本 | 初始无伪造示例数据、记账、修改无续费记录、目标基金、本月分类与分摊展开、取消及确认作废 |
| 家庭记录 | 资料与链接保存、无链接的文字记忆、只填标题保存、可选日期地点、分类筛选 |
| 异常恢复 | 加载失败显示重试、重试恢复数据、保存失败保留输入、重新保存成功、取消危险操作保留数据 |
| 隐私与帮助 | 说明可阅读、反馈定位信息、退出本机登录；复制操作另用 JS 检查实际传入内容，不覆盖系统剪贴板 |

## 回归检查

- `npm run release:local-gate`：通过，包含所有 workspace 类型检查，以及模板事件、鉴权重试、分页、MVP、首页、首屏回归、设计回归和交付工具检查。
- `npm run test:postgres`：34 项真实数据库 / API / 权限检查通过。
- 布局：320、390、430 三种宽度，54 个页面/表单/详情/邀请/资料状态通过；另做长家庭名、长活动标题、长记录标题及反馈信息检查。
- 首页单独回归：320、390 两种宽度，日常、空状态、切换、欢迎、错误状态通过。
- 新增设计回归覆盖重复保存、旧家庭的迟到响应、日期同步、非法链接/日期、活动转存后的记录缓存更新、邀请码切换及复制内容。

## 验收中修复的问题

1. 微信写操作没有业务字段时仍发送合法 JSON 对象，修复活动转存、退出登录和撤销邀请。
2. 无续费账目、无指定负责人提醒的修改请求省略数据库空值，避免接口拒绝保存。
3. 活动与家庭记录创建时省略未填写的可选文字，支持只填必填项。
4. 去掉会被误保存的账目、目标和记录示例值，记忆不默认标记某位家人。
5. 切换家庭及离开页面后不应用旧请求；活动转存后返回记录页刷新缓存。
6. 账本摘要改为明确的上下结构，修复原生布局差异；长标题换行；统一日期显示。
7. 邀请先校验再显示加入表单，换码丢弃旧校验结果，无效卡片仍可输入新的邀请码。

交付为小程序预览版，正式版继续由产品验收决定。
